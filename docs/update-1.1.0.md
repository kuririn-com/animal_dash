# Animal Dash 1.1.0 — 未公開の更新準備

審査中の1.0.0とは別の更新用ブランチです。App Store Connectのバージョン・選択ビルド・審査申請には変更を加えません。

## 修正

- 地面を現在のゲーム領域の全幅に毎回描画。広告表示・購入状態による画面幅の変化にも追従します。
- StoreKitが返す実際のJPY価格を日本語の「100円」形式で表示。USDなどを円に読み替えません。JPY価格が取得できない場合は購入を無効にしてストア地域の案内を表示。復元は引き続き利用できます。
- BGMにiOSのambientカテゴリを使用。マナーモード・本体音量に追従し、アプリ内にも音量スライダーを追加します。

## コイン・所持品

- 取ったコインは累積残高として端末へ保存。トップの「コイン交換・もちもの」で交換できます。
- 旧版の最高距離・最高コイン記録を維持。最高コイン記録は累積残高ではないため、交換用コインには換算しません。
- 未使用アイテムは複数個保存でき、次のプレイにも持ち越せます。プレイ中の地面下部にあるボタンから1個ずつ使用します。
- バリアは使用した分だけ防御回数が増えます。衝突後0.8秒間は追加の衝突で連続消費しません。
- 時間制アイテムは重ねて使用すると残り時間が増えます。使用済みの効果はゲーム終了でリセットされます。
- プレイ中に拾ったアイテムの即時発動は維持しています。
- コイン購入や現金でのアイテム販売はありません。

## キャラクター・衣装

- ランナー：最初から使用可能、うさぎ：60コイン、ねこ：80コイン。
- レッド：最初から使用可能、ブルー・グリーン：各25コイン、ゴールド：100コイン。
- 解放は一度だけ。選択と解放状態を端末に保存します。性能・当たり判定は共通です。

## 背景と障害物

背景は各プレイ開始時に抽選し、プレイ中には切り替えません。抽選は独立しているため連続して同じ背景になる場合もあります。

|背景|確率|
|---|---:|
|晴れ|30%|
|曇り|20%|
|雨|14%|
|夕方|12%|
|雪|8%|
|夜|8%|
|桜|5%（レア）|
|雷|3%（レア）|

桜では木がピンク色になり花びらが舞います。雷は小さな稲妻で、全画面の閃光は使いません。天候による当たり判定・速度の変化はありません。

障害物も毎回抽選します。モグラは全出現の3%。残り97%の内訳は箱18、人8、犬14、うさぎ10、ダックス12、ねこ12、きつね8、ひつじ8、鳥5、かえる3、いのしし2の重みです。

## BGM

既存のSUNO音源を保持し、サンプル音源を使わず合成した新規の短いループ3曲を追加しています。

- ひだまりダッシュ（約29秒）
- さくらステップ（約36秒）
- 星空ランウェイ（約34秒）

トップの「BGM・背景の出現率」で4曲から選べます。音源作成の再現用コードはtools/compose_bgm.pyです（PythonとNumPyが必要）。
