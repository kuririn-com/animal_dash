# Animal Dash — 初回再審査に向けた追加機能候補

元は審査通過後の1.1.0用に準備した機能です。初回1.0.0(6)の4.3 / 4.2.6指摘を受け、初回版の実質的な改修候補として統合しています。まだ再提出していません。マーケティングバージョンは初回の1.0.0を維持し、次のビルド番号はビルド時に取得します。

## 修正

- 地面を現在のゲーム領域の全幅に毎回描画。広告表示・購入状態による画面幅の変化にも追従します。
- StoreKitが返す実際のJPY価格を日本語の「100円」形式で表示。審査・Sandbox等で他の通貨が返る場合は実際の表示価格を維持し、日本正式価格100円との違いを説明します。JPYでないことだけを理由に購入を無効にせず、Appleの確認画面で実通貨と金額を確認できます。復元も利用できます。
- 1.0.0(6)の一時停止・再開・バックグラウンド時の停止を追加機能版にも統合。停止中は所持品を消費せず、距離・障害物・効果時間も進みません。
- BGMにiOSのambientカテゴリを使用。マナーモード・本体音量に追従し、アプリ内の曲・音量・背景設定は設けません。

## コイン・所持品

- 初回は0コイン・所持アイテムなし。取ったコインは累積残高として端末へ保存。トップの「コイン交換・もちもの」で交換できます。
- 旧版の最高距離・最高コイン記録を維持。最高コイン記録は累積残高ではないため、交換用コインには換算しません。
- 未使用アイテムは複数個保存でき、次のプレイにも持ち越せます。プレイ中の地面下部にあるボタンから1個ずつ使用します。
- バリアは使用した分だけ防御回数が増えます。衝突後0.8秒間は追加の衝突で連続消費しません。
- 時間制アイテムは重ねて使用すると残り時間が増えます。使用済みの効果はゲーム終了でリセットされます。
- 爆発（障害物クリア）は使用時の障害物を即座に消す単発効果です。5秒の持続・カウント表示はありません。次に出現する障害物には効果がありません。
- プレイ中に拾ったアイテムの即時発動は維持しています。
- コイン購入や現金でのアイテム販売はありません。

## キャラクター・衣装

- ランナー：最初から使用可能、うさぎ・ねこ：各200コイン、スペシャルの王冠ライオン：500コイン。ねこには左右3本ずつの髭、ライオンにはたてがみ・髭・王冠・マント・金の縁取りの王様風衣装を付けています。
- レッド：最初から使用可能、忍者（頭巾・赤いスカーフ）、森のレンジャー（羽根付き帽子・マント・ポーチ）、黄金の勇者（兜・鎧・盾）：各500コイン。保存済みの旧ブルー・グリーン・ゴールドは、それぞれ対応する衣装に引き継ぎます。王冠ライオンは選んだ色の王様風衣装を着ます。
- 解放は一度だけ。選択と解放状態を端末に保存します。性能・当たり判定は共通です。

## 背景と障害物

背景は各プレイ開始時に抽選し、プレイ中には切り替えません。抽選は独立しているため連続して同じ背景になる場合もあります。

|背景|確率|
|---|---:|
|晴れ|30%|
|曇り|20%|
|雨|14%|
|夕方|12%|
|雪|8%|
|夜|8%|
|桜|5%（レア）|
|雷|3%（レア）|

桜では木がピンク色になり花びらが舞います。雷は小さな稲妻で、全画面の閃光は使いません。天候による当たり判定・速度の変化はありません。

障害物も毎回抽選します。モグラは全出現の3%。残り97%の内訳は箱18、人8、犬14、うさぎ10、ダックス12、ねこ12、きつね8、ひつじ8、鳥5、かえる3、いのしし2の重みです。

## BGM

既存のSUNO音源を保持し、サンプル音源を使わず合成した新規の短いループ3曲を追加しています。

- ひだまりダッシュ（約29秒）
- さくらステップ（約36秒）
- 星空ランウェイ（約34秒）

4曲からプレイごとに均等にランダム抽選します。背景も既定の確率で抽選し、選択・設定項目は表示しません。以前の曲・音量設定は引き継がず、本体音量で調整します。音源作成の再現用コードはtools/compose_bgm.pyです（PythonとNumPyが必要）。

- 新版のApp Store情報・プライバシーポリシーの公開側の追記は、新版公開準備時に行います。
- 独自性の説明と開発者本人の事実確認、改修後の実機ベータが済むまでは再提出しません。
- 衣装や背景の追加だけで4.3 / 4.2.6の指摘が解消されたとは判断しません。コイン交換・保存済み所持品の使い分けという実際のゲームループの差を説明します。
