タップでジャンプ！動物ランゲーム

Animal Dash サポート

動物たちや障害物を飛び越えながら、コインを集めて最高記録に挑戦するランゲームです。iPhone・iPadを横向きにして遊べます。

遊び方

「スタート」をタップして開始。画面をタップするとジャンプし、空中でもう一度タップすると2段ジャンプできます。ゲーム終了後は「再開」でやり直すか、「タイトルへ」でタイトルに戻れます。

よくある質問

記録はどこに保存されますか？

最高距離と最高コイン数は端末内に保存されます。アカウント登録は不要です。アプリを削除すると記録も削除されます。

広告が表示されません。

通信状況や広告の配信状況、同意状態等により表示されない場合があります。広告を取得できない場合もゲームを続けられます。

操作や表示に問題があります。

アプリを最新版に更新し、一度終了してから開き直してください。改善しない場合は、端末名・iOSバージョン・アプリのバージョン・問題が起きる操作をお問い合わせ時にお知らせください。

広告を削除する・購入を復元する

基本プレイは無料・広告ありです。タイトル画面の「広告を削除・購入を復元」から、買い切りのアプリ内課金でバナー広告と全画面広告を削除できます。月額料金はありません。価格は購入画面に表示されるApp Storeの価格をご確認ください。

機種変更や再インストール後は、購入時と同じApple Accountで「購入を復元」を選んでください。購入の承認待ちの場合は、Appleによる承認後に反映されます。
